# Third-party dependency inventory

Treta source is proprietary. Third-party packages retain their own licences.

The authoritative resolved versions are `uv.lock` and `pnpm-lock.yaml`. Direct runtime dependencies are FastAPI, Pydantic, PyYAML, Uvicorn, Svelte, and SvelteKit. The verified frontend toolchain includes Vite 8.1.5 and Vitest 4.1.10; the verified backend test toolchain includes pytest 9.1.1. Development dependencies provide testing, formatting, typing, linting, and security auditing. A generated licence report and SBOM are future release-gate work; dependency addition requires licence and security review.
